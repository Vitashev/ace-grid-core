# Contributing to Core

Use Node.js 22.12 or newer (Node 20.19 also works). `.nvmrc` selects Node 22.
Install from the repository root using the committed lockfile:

```sh
npm ci
npm run build
npm test
npm run test:types
```

The build bundles `src/core.ts` to ESM and CommonJS and runs TypeScript to emit
checked declarations in `dist`. React and ReactDOM stay external to the library.
The smoke tests load both module formats and mount, sort, and update Core in
jsdom. They do not replace browser layout, virtualization, or drag-and-drop tests.

## Exercise your source changes

The default React starter intentionally uses the published `@ace-grid/core`
package so it can run independently in StackBlitz. To exercise this checkout:

```sh
cd examples/react-basic
npm ci
npm run dev:local
# or a type-checked production build:
npm run build:local
```

Local mode resolves `@ace-grid/core` directly to `../../src/core.ts`, without
requiring a prior library build. Vite deduplicates React and ReactDOM to the
example's installation. The local TypeScript configuration checks the same source.
Root and example dependencies must both be installed.

To test the published-package starter instead, run `npm run dev` or
`npm run build` in the example. Those commands retain the registry dependency.

## Generated source and synchronization

This repository is synchronized from the canonical source workspace. Core-only
support contracts and import rewrites are generated by its Core exporter;
contributor tooling is applied by its public synchronization helper. Coordinate
changes to generated files with those canonical templates so a subsequent export
preserves the fix. Contributors do not need access to that workspace to build or
test this repository. Do not run release scripts for contributor verification.
